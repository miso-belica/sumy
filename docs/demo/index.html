sumy in the browser

The same sumy you install with pip, running as WebAssembly on this page. Nothing is uploaded anywhere: Pyodide starts CPython in a WASM sandbox and micropip installs sumy into it straight from PyPI.

Starting Python…

    Installed in the page with await micropip.install("sumy") — possible because PyPI now accepts wheels for the PyEmscripten platform of PEP 783. sumy is pure Python, so its ordinary py3-none-any wheel is what runs here.
